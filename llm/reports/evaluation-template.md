## 4. 사례 분석

### 개선된 사례
- (id) 학습 전 → 학습 후, 무엇이 나아졌는지

### 악화된 사례
- (id) 학습 전 → 학습 후, 무엇이 나빠졌는지

### 실패 원인 추정
- 데이터: 범주별 건수 부족, 특정 형식 편중, 초안 오류
- 문맥: 길이, 근거 위치
- 학습: epoch·lr 과다(암기·과적합 징후: train loss만 하락, validation loss 상승), 과소 학습
- 생성: greedy 반복, max_new_tokens 부족
- 모델: 기반 모델의 한국어·지시 수행 한계
